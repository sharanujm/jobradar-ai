JobRadar AI 2.0 • System Architecture & Engineering Whitepaper

Autonomous multi-source job discovery, strict experience boundaries, ATS resume scoring, non-blocking SQLite WAL concurrency, and scheduled cloud email delivery platform.

Lead Engineer: Sharanu ❤️ Status: Production Live (v2.0) Runtime: Python 3.11 / FastAPI / Uvicorn Database: SQLite 3 (WAL Mode, 60s Busy Timeout) Target Region: India • Tech Hubs & Remote

1. Executive Summary & Product Vision

JobRadar AI 2.0 is an autonomous career acceleration engine designed specifically for technical job hunters in India. It eliminates manual job hunting fatigue by aggregating freshly posted engineering roles across multiple platforms, extracting exact experience boundaries, scoring candidate resume alignment, and dispatching curated email digests.

  • Continuous Ingestion: Crawls LinkedIn, Indeed, Naukri, Glassdoor, Internshala, and Google Jobs.
  • Zero-Spam Experience Parser: Guarantees freshers (0–2 years) are never shown jobs that secretly require 3–8 years.
  • Cloud Email Delivery over HTTPS: Bypasses cloud container SMTP firewall blocks using Resend & Brevo HTTPS APIs (Port 443).
  • Full Career Suite: ATS Resume Matcher, Kanban Application Tracker, Cold Pitch Generator, Tech Study Vault, and AI Mock Interviews.

4. Core Subsystems & Deep-Dive Implementation

4.1 Multi-Board Job Scraping & Anti-Bot Engine

Aggregates fresh technical postings across 6 major portals. Uses curl_cffi to bypass TLS fingerprint detection and computes a deterministic SHA-256 hash for deduplication: 

raw = f"{site.lower()}|{title.lower().strip()}|{company.lower().strip()}|{clean_url}"
job_id = hashlib.sha256(raw.encode("utf-8")).hexdigest()

4.2 Strict Experience Parsing & Boundary Classifier

Solves the widespread problem of senior jobs being labeled "Entry-Level". The engine applies a multi-stage classification pipeline:

  • URL Path Scanner: Detects experience ranges embedded in job slugs (e.g. -3-to-8-years, -5-to-10-years).
  • Title Seniority Heuristics: Reclassifies titles containing SDE II, Senior, Lead, Principal, or Architect into mid/senior buckets.
  • Contextual Snippet Parsing: Extracts exact numerical boundaries (0–2 yrs vs 3–6 yrs) while discarding unrelated numbers (e.g. "5 days working").

4.3 Resume Studio & AI ATS Matcher

Parses resumes using pypdf and matches against 100+ technical skills. Calculates match percentage based on: 

Match Score = (Skill Match Rate × 0.60) + (Role Relevance × 0.25) + (Experience Alignment × 0.15)

4.4 Automated Pre-Scrape & Daily Email Engine (IST)

Operates in Asia/Kolkata (IST):

  • Pre-Digest Auto-Scrape: Launches a scraper 30 minutes before the candidate's scheduled email time.
  • Personalized Digest: Builds and delivers 100 fresh, unemailed India jobs matching the candidate's exact experience tier and tech stack.
  • Catch-Up Delivery: Automatically dispatches missed digests if the user changes their schedule to an earlier time.

4.5 Cloud HTTPS Email Transport (Render Free Tier Safe)

Cloud container hosts (Render, AWS, DigitalOcean) block outbound SMTP ports (25, 465, 587). JobRadar AI uses modern REST APIs over Port 443 HTTPS:

Brevo API https://api.brevo.com/v3/smtp/email 443 (HTTPS) 100% OPEN • Backup

4.6 Application Kanban Tracker

Tracks job applications across state transitions: Wishlist → Applied → Interviewing → Offered / Rejected. Includes interview dates, custom candidate notes, and conversion analytics.

6. Database Architecture & WAL Concurrency

To eliminate sqlite3.OperationalError: database is locked, the system configures: 

def get_connection(db_path: Path = DB_PATH) -> sqlite3.Connection:
    conn = sqlite3.connect(str(db_path), timeout=60.0, check_same_thread=False)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA journal_mode = WAL;")       # Non-blocking concurrent reads & writes
    conn.execute("PRAGMA busy_timeout = 60000;")     # Wait up to 60s instead of failing
    conn.execute("PRAGMA synchronous = NORMAL;")     # Fast and safe disk I/O
    return conn

8. Security, Performance & Resilience

  • Protected Credentials: Passwords hashed with SHA-256; API keys protected in admin cards.
  • Connection Safety: All queries enclosed in try ... finally: conn.close() to prevent open locks.
  • Safe Client Parsing: safeParseResponse prevents Unexpected token 'I' during server wakeups.

9. Local Setup & Quickstart

# 1. Clone repository
git clone https://github.com/sharanujm/jobradar-ai.git
cd "Job automation"

# 2. Set up virtual environment
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # Linux/macOS

# 3. Install requirements
pip install -r requirements.txt

# 4. Start local development server
python -m uvicorn server:app --reload --port 8765

Open http://localhost:8765 to explore the live dashboard.
